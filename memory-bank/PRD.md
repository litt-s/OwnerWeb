# OwnerWeb PRD

> 本文档用于说明 OwnerWeb 要做什么、线上版本长什么样。它不讨论具体实现，技术约束见 `TECH_STACK.md`，页面结构见 `DESIGN.md`，数据与接口见 `DATA_MODEL.md`。
>
> 本文档已按**当前线上版本**（Cloudflare Pages + Workers + D1 + KV + 腾讯云 COS）同步。

## 1. 项目一句话说明

OwnerWeb 是李浩然的嵌入式软件工程师个人作品集网站，用于向招聘方、导师和同行展示个人经历、项目能力、技术优势，并提供注册登录、留言评论、账号设置和内容管理能力。

## 2. 项目目标

- 展示个人身份、教育背景、联系方式和嵌入式开发方向。
- 用可交互的 3D PCB 与 3D 硬币作为首页与个人介绍页的核心视觉。
- 展示精选项目列表与详情页，表达硬件、系统、协议和云平台的完整实现链路。
- 提供访客留言和项目多级评论，支持分页与按线程展开回复。
- 提供账号注册、登录、账号设置、头像上传和密码修改。
- 提供管理员后台，管理评论、用户、项目、个人优势和站点基础内容。
- 线上可访问（`https://ownerweb.pages.dev`），国内网络可正常打开。

## 3. 目标用户

### 访客

招聘方、面试官、老师、同学或技术同行。他们希望快速了解：

- 李浩然是谁，擅长什么方向。
- 他做过哪些真实系统，解决了什么问题。
- 项目里体现了哪些嵌入式和物联网能力。
- 如何联系他，或留下进一步交流的信息。

### 注册用户

注册用户可以维护自己的昵称、头像和密码，并参与留言与项目评论。角色只有普通用户和管理员两种。

### 管理员

管理员是站长本人，可以：

- 管理评论（查看访客留言与项目评论、删除）。
- 管理项目（新增、编辑、删除、排序、封面上传、视频上传/外链、设置「仅登录可查看」）。
- 管理个人优势（新增、编辑、删除、排序）。
- 编辑站点内容（Hero 文案、身份与联系、教育与认证、个人经历、联系我区块标题）。
- 管理用户（查看列表、调整角色、封禁/解封、删除）。

## 4. 核心使用场景

- 访客打开首页，先看到动态极光背景上的 3D PCB 与「用逻辑，点亮硬件」的职业定位。
- 访客拖动 PCB 查看各角度，点击板上热点（MCU / 排针 / 晶振 / USB / 蜂鸣器）跳转到对应板块。
- 访客浏览个人经历（含 3D 硬币头像卡）、精选项目和个人优势。
- 访客进入项目详情页，观看演示视频、阅读项目介绍和核心实现；未登录时受限项目只显示锁定卡片。
- 访客在访客留言页或项目详情页留言、回复；列表分页加载，回复按线程展开。
- 用户注册并登录后，维护昵称、头像和密码。
- 管理员登录后台，管理评论、项目、优势、站点内容和用户。

## 5. 页面与布局（对齐线上）

### 5.1 顶部导航（全站固定）

- 悬浮胶囊条，滚动后加强阴影/描边。
- 左侧品牌：芯片 SVG 图标 + 文字「Li的个人博客」；点击（图标或文字）返回首页并回到顶部。
- 中间：站内搜索（姓名 / 项目 / 技能），输入即出下拉结果。
- 管理员登录时额外显示「后台」入口。
- 右侧：未登录显示「登录 / 注册」；已登录显示「昵称（账号设置）」与「退出」；始终显示「联系我」按钮。
- 移动端（≤680px）：导航换行、隐藏品牌文字、搜索占满一行。

### 5.2 首页 `/`

按顺序排列：

1. **Hero**：动态极光背景 + 暗角；可交互 3D PCB（STM32 风格），带 5 个可点击热点与引出线标注（精选项目 / 个人经历 / 个人优势 / 联系我 / 访客留言）；支持拖动旋转、悬停高亮；标题「用逻辑，点亮硬件」+ 副标题（均可在后台编辑）。
   - 窄屏（≤820px）：隐藏板外标注，改在 PCB 下方显示按钮导航「精选项目 / 个人经历 / 个人优势 / 访客留言 / 联系我」。
2. **个人经历**：左侧头像卡（3D 金属硬币 + 凹腔 + 视差），右侧经历简介、教育背景、专业认证、联系方式列表、经历统计。
3. **精选项目**：左右交替的项目卡片（封面 / SVG 兜底、编号角标、名称、英文名、定位、简介、核心实现、技术标签、仓库文字）；受限项目显示锁定卡片。
4. **个人优势**：6 张能力卡片。
5. **联系我 + 页脚**：联系区大标题、小标签（均可在后台编辑）、邮箱大按钮、渠道卡片（邮箱 / 电话 / 微信 / 仓库平台 / 所在地）；页脚含版权、技术方向与「回到顶部」。

### 5.3 个人经历 `/experience`

- 顶部「返回首页」（SVG 箭头）+ 页面标题。
- 内容与首页「个人经历」区块一致。

### 5.4 精选项目 `/projects`

- 顶部「返回首页」+ 页面标题。
- 项目卡片列表（与首页一致）。

### 5.5 项目详情 `/projects/:id`

- 顶部「返回首页」+ 项目名标题。
- 项目头：名称、英文名、一句话定位、技术标签。
- 演示视频：**填写了视频地址才渲染**（支持腾讯云 COS 直链、B站 / YouTube 嵌入、`.mp4` 等直链）；加载失败显示提示与「在新窗口打开」。
- 项目介绍、核心实现列表、仓库链接。
- 项目留言：顶层评论分页 + 「查看 N 条回复 / 收起回复」。
- 底部「← 返回精选项目」。
- 受限项目：未登录只显示锁定卡片；详情页显示「该作品需要登录后查看 + 去登录」。

### 5.6 个人优势 `/strengths`

- 顶部「返回首页」+ 页面标题；能力卡片列表。

### 5.7 访客留言 `/comments`

- 顶部「返回首页」+ 页面标题。
- 留言表单：未登录显示「登录后参与留言 + 去登录」；登录后可提交。
- 留言列表：顶层留言分页（「加载更多评论」），每条可「查看 N 条回复 / 收起回复」，支持任意层级回复。

### 5.8 登录 / 注册 `/auth`

- 卡片式，两个页签：登录 / 邮箱注册。
- 登录：邮箱、密码（可切换显示）。
- 注册：昵称、邮箱、密码、确认密码（可切换显示）。
- 邮箱即时格式校验；提交时后端校验格式、常见拼写错误域名、一次性邮箱域名、域名 MX 记录。
- 错误提示直接显示在表单内。

### 5.9 账号设置 `/settings`

- 未登录访问自动跳转 `/auth`；登录态加载中显示提示。
- 左侧头像卡（上传头像，带上传进度条）。
- 基本资料：昵称（可改）、邮箱（只读）、保存资料。
- 修改密码：原密码、新密码、确认新密码、修改密码。
- 保存/修改按钮带 loading 状态。

### 5.10 管理后台 `/admin`

- 未登录跳转 `/auth`；非管理员显示无权提示；仅管理员触发数据请求。
- 五个页签：
  - **内容管理**：Hero 文案；身份与联系（姓名、职业定位、邮箱、电话、拨号号码、所在地、微信号、**仓库托管平台复选框 Gitee / GitHub / GitCode + 用户名 + 链接**、技术方向）；教育与认证（学校、专业、时间、专业认证）；个人经历（简介 + 统计增删）；**联系我（大标题、小标签）**；保存内容。
  - **评论管理**：位置、昵称、时间、内容、操作；删除前二次确认。
  - **项目管理**：列表（项目、排序、封面、操作）+ 新增；编辑器分「基本信息」「展示与链接（含仓库地址、仓库显示文字、**仅登录用户可查看**）」「视频与封面（演示视频链接 + **上传视频到 COS**（带进度）+ 项目封面 + 上传/替换封面（带进度））」；删除前二次确认。
  - **优势管理**：优势增删改与排序。
  - **用户管理**：用户、昵称、注册时间、角色、操作（设为管理员/普通、封禁/解封、删除）；封禁与删除前二次确认。

## 6. 功能范围

### 6.1 线上已实现

- 首页 Hero + 3D PCB 交互 + 个人经历 + 项目列表 + 优势 + 联系区。
- 独立页面：个人经历、精选项目、项目详情、个人优势、访客留言。
- 站内搜索（姓名 / 项目 / 技能）。
- 项目详情：演示视频（COS 直链 / B站 / YouTube / 直链，未配置则不显示视频区）、标签、长介绍、核心实现、仓库外链。
- 项目评论：任意层级回复、顶层分页、按线程懒加载。
- 注册 / 登录 / 退出；注册邮箱校验（格式、拼写纠错、一次性邮箱黑名单、域名 MX）。
- 账号设置：昵称、头像上传、密码修改。
- 管理员后台：评论 / 项目 / 优势 / 站点内容 / 用户管理，删除与封禁二次确认。
- 仓库托管平台可自主选填（Gitee / GitHub / GitCode），前台按已选平台展示并可跳转。
- 联系我区块标题可编辑。
- 项目「仅登录用户可查看」：未登录只返回锁定卡片，详情返回 401。
- 项目视频上传到腾讯云 COS（后端预签名、后台直传，数据库只存链接）。
- 移动端适配与性能优化（3D 场景离屏暂停、移动端降 DPR / 关抗锯齿）。
- 部署：Cloudflare Pages（前端）+ Workers / D1 / KV（后端）+ 腾讯云 COS（视频）。

### 6.2 暂不做

- 多语言切换。
- 博客 / 文章发布系统。
- 邮箱验证码 / 验证链接与找回密码（当前只做邮箱格式与域名可收信校验）。
- 第三方 OAuth 登录。
- 站内私信。
- 留言点赞与审核流。

## 7. 验收标准

- 首页与所有一级页面在桌面端和移动端均能正常浏览。
- 首页 3D PCB 可拖动、热点可点击并跳转正确；窄屏显示按钮导航。
- 项目列表至少展示 2 个项目，点击进入正确详情页。
- 项目详情页展示完整介绍、核心实现、技术标签和外链；未配置视频时不显示视频区，配置后正常播放。
- 注册（含邮箱校验）、登录、退出流程可用，刷新后登录态可恢复。
- 未登录访问 `/settings`、`/admin` 会被拦截（跳转登录 / 无权提示）。
- 登录用户可修改昵称、上传头像（有进度）、修改密码。
- 未登录用户不能留言，页面提供登录入口。
- 留言与项目评论可分页加载，回复可按线程展开与收起。
- 管理员可删除评论、删除/封禁用户（均有二次确认）。
- 管理员可新增/编辑/删除项目，上传封面（有进度）、上传视频到 COS 或填外链，设置「仅登录可查看」。
- 管理员可编辑 Hero、身份与联系（含仓库平台）、教育与认证、经历、联系我标题；保存后前台同步更新。
- 受限项目：未登录显示锁定卡片，登录后可见完整内容。
- 项目构建成功，接口错误在页面上有明确提示。
