# OwnerWeb PRD v0

> 本文档用于说明 OwnerWeb 要做什么。它不讨论具体实现，技术约束见 `TECH_STACK.md`。

## 1. 项目一句话说明

OwnerWeb 是李浩然的嵌入式软件工程师个人博客，用于向招聘方、导师和同行展示个人经历、项目能力、技术优势，并提供登录、留言和账号设置能力。

## 2. 项目目标

这个项目希望完成：

- 展示个人身份、教育背景、联系方式和嵌入式开发方向。
- 展示精选项目列表，初始数据包含鸿婴云护和智耘，后续项目可由管理员维护。
- 用清晰的项目详情页表达硬件、系统、协议和云平台的完整实现链路。
- 提供独立的访客留言和项目多级评论，让访问者可以针对页面内容互动。
- 提供账号注册、登录、账号设置、头像上传和密码修改。
- 提供管理员后台，管理评论、用户、项目内容、个人优势和站点基础内容。

## 3. 目标用户

### 访客

访客是招聘方、面试官、老师、同学或技术同行。他们打开网站时希望快速了解：

- 李浩然是谁，擅长什么方向。
- 他做过哪些真实系统，解决了什么问题。
- 项目里体现了哪些嵌入式和物联网能力。
- 如何联系他，或留下进一步交流的信息。

### 注册用户

注册用户可以维护自己的昵称、头像和密码，并参与留言互动。第一版只有普通用户和管理员两种角色。

### 管理员

管理员是站长本人。管理员可以：

- 查看全部留言。
- 删除不合适的留言。
- 新增、编辑和删除项目。
- 上传或替换项目视频和封面；删除项目前进行二次确认。
- 新增、编辑、删除个人优势，并调整排序。
- 编辑首页 Hero、个人身份、联系信息、教育认证和经历内容。
- 查看用户列表。
- 调整用户角色。
- 封禁、解封或删除用户。

## 4. 核心使用场景

- 访客打开首页，先看到“用逻辑，点亮硬件”的职业定位和嵌入式方向简介。
- 访客浏览个人经历、精选项目和个人优势。
- 访客进入项目详情页，观看演示视频、阅读项目介绍和核心实现。
- 访客在项目详情页查看并参与多级项目评论，或在访客留言页提交通用留言。
- 用户注册并登录后，可以维护个人资料和密码。
- 管理员登录后进入后台，管理评论、项目内容、个人优势、站点基础内容和用户。

## 5. MVP 功能范围

第一版必须完成：

- 首页展示 Hero、个人经历、项目列表、个人优势和联系方式。
- 独立页面展示个人经历、精选项目、个人优势和访客留言。
- 项目详情页展示项目视频、标签、长介绍、核心实现和外链。
- 用户可以注册、登录、退出。
- 登录用户可以修改昵称、头像和密码。
- 登录用户可以提交访客留言、项目评论，并回复任意层级的项目评论。
- 管理员可以删除留言。
- 管理员可以新增、编辑、删除项目，上传或替换项目视频和封面。
- 管理员删除项目前必须二次确认；确认后项目及其评论一并删除。
- 管理员可以新增、编辑、删除个人优势，并调整展示排序。
- 管理员可以编辑首页 Hero、个人经历、教育认证和联系方式。
- 管理员可以查看、调整、封禁和删除用户。

第一版不做：

- 多语言切换。
- 博客或文章发布系统。
- 邮箱验证和找回密码。
- 第三方 OAuth 登录。
- 站内私信。
- 留言点赞、审核流和分页。

## 6. 页面清单

| 页面 | 路由 | 说明 |
|------|------|------|
| 首页 | `/` | Hero + 经历 + 项目 + 优势 + 联系方式 |
| 个人经历 | `/experience` | 教育背景、职业介绍和经历信息 |
| 精选项目 | `/projects` | 项目卡片列表 |
| 项目详情页 | `/projects/:id` | 项目详情、演示视频、核心实现、项目多级评论 |
| 个人优势 | `/strengths` | 嵌入式相关能力清单 |
| 访客留言 | `/comments` | 独立的通用留言区和回复 |
| 登录 / 注册 | `/auth` | 邮箱账号登录与注册 |
| 账号设置 | `/settings` | 昵称修改、头像上传、密码修改 |
| 管理后台 | `/admin` | 内容管理、评论管理、项目管理、优势管理和用户管理 |

## 7. 验收标准

项目完成时必须满足：

- 首页和所有一级页面在桌面端和移动端均能正常浏览。
- 首页能清晰传达“嵌入式软件开发工程师”的定位。
- 项目列表至少展示 2 个项目，点击后能进入正确详情页。
- 项目详情页能展示完整介绍、核心实现、技术标签和外部链接。
- 注册、登录、退出流程可用，登录状态刷新后仍能恢复。
- 登录用户可以修改昵称、密码并上传头像。
- 未登录用户不能提交留言，页面提供登录入口。
- 登录用户可以提交访客留言和项目评论。
- 项目评论支持回复任意层级评论，页面按评论树展示。
- 管理员可以删除留言，删除后列表同步更新。
- 管理员可以新增、编辑和删除项目；删除前会收到二次确认。
- 管理员可以上传或替换项目视频和封面。
- 管理员可以新增、编辑、删除个人优势，并调整排序。
- 管理员可以修改 Hero、经历简介、经历统计、教育认证和联系信息；保存后前台同步更新。
- 管理员可以查看用户、调整角色、封禁、解封和删除用户。
- 管理员不能删除自己，也不能封禁自己。
- 项目构建成功，接口错误在页面上有明确提示。
