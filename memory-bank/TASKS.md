# OwnerWeb 开发任务清单

> 本文档是 OwnerWeb 的开发任务清单，用于拆解后续开发工作、标记任务状态，并约束每次任务的执行方式。

## 执行规则

1. 每次只做一个编号任务。
2. 开始前阅读 `memory-bank/` 中相关文档。
3. 不实现任务清单之外的功能。
4. 完成后更新 `memory-bank/PROGRESS.md`。
5. 改动架构或数据字段时，同步更新 `ARCHITECTURE.md` 或 `DATA_MODEL.md`。
6. AI 协作期间不发送图片、截图或非文本消息。
7. AI 不自动打开浏览器；需要查看页面时只提供文本链接。
8. 任何代码、依赖、配置、路由、页面、视觉、接口、数据库、部署或验收范围变化，都必须在任务结束前同步更新对应的 `memory-bank/` 文档。
9. 文档同步是任务完成标准的一部分；只改代码不同步文档，任务不算完成。
